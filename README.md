# CREDIT-ULFS

This repository contains the **Antenna.ipynb** notebook, which can be opened and executed directly in **Google Colab** for easy access and use.

## 🚀 How to Open in Google Colab

Follow these steps:

1. Go to [Google Colab](https://colab.research.google.com/).  
2. Select **File → Open notebook**.  
3. In the left panel, choose the **GitHub** tab.  
4. In the search bar, enter:  CREDIT-ULFS
5. Press **Enter**, then select the file **Antenna.ipynb** from the list.  
6. The notebook will open in Colab — you can now run it directly in your browser.
